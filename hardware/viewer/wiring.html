Two-microphone wiring

Both microphones share the I²S clocks and data input. Their L/R pins select opposite stereo slots. The OLED uses the separate I²C pins.

3.3 V only: never connect microphone or OLED logic to a 5 V GPIO pin.

Verified I²S: SCK → pin 12, WS → pin 35, SD → pin 38, VDD → pin 1, GND → pin 6.

Shared bus: matching SCK, WS and SD pins from both microphones join together.

Channel select: left L/R → GND; right L/R → 3.3 V. Never leave L/R floating.

Data pull-down: use one 100 kΩ resistor from the shared SD line to GND unless the breakout already includes it.
